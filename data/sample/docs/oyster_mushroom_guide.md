# 느타리버섯 재배 관리 샘플 매뉴얼 (SAMPLE)

> 이 문서는 시스템 시연용 샘플 문서임. 일반적인 재배 상식 수준으로 작성했으며 공식 매뉴얼이 아님.
> 출처를 기재하지 않은 수치에는 `[일반 권장값, 출처 확인 필요]`를 붙였음. 실제 재배에는 농촌진흥청 등 공식 재배 매뉴얼을 `data/raw/docs/`에 넣어 사용할 것.

## 1. 개요
느타리버섯은 볏짚, 톱밥, 폐면, 비트펄프 등 다양한 배지에서 재배할 수 있는 식용 버섯임. 재배 방식은 크게 병재배, 봉지재배, 균상재배로 나뉨. 재배 단계는 배지 준비 → 살균 → 냉각 → 접종 → 균사 배양 → 발이(원기 형성) 유도 → 자실체 생육 → 수확 순서로 진행됨. 단계마다 요구하는 온도·습도·이산화탄소(CO2)·광 조건이 다르므로 단계별로 재배사 환경을 따로 관리해야 함.

## 2. 배지 준비와 살균
- 배지 재료는 곰팡이가 피거나 변질되지 않은 것을 사용함.
- 배지 수분은 손으로 쥐었을 때 물이 약간 배어나오는 정도로 맞춤. 수분 함량 약 60~65 % [일반 권장값, 출처 확인 필요].
- 살균이 불충분하면 푸른곰팡이 등 잡균 오염의 주원인이 되므로, 살균 온도와 시간을 기록하고 배지 내부 온도까지 확인함.
- 살균 후에는 깨끗한 냉각실에서 배지 온도를 충분히 낮춘 다음 접종함. 냉각 중 외부 공기 유입을 줄임.

## 3. 접종과 균사 배양
- 접종실은 작업 전 소독하고, 작업자 손·도구·종균병 입구를 소독함.
- 균사 배양 온도는 약 20~25 ℃ [일반 권장값, 출처 확인 필요]가 일반적으로 권장됨. 배양 중 배지 내부는 균사 호흡열로 실내 온도보다 높아질 수 있어 배지 온도를 함께 확인함.
- 균사 배양 단계에서는 빛이 거의 필요하지 않으며, 실내 습도는 약 65~70 % [일반 권장값, 출처 확인 필요] 수준으로 관리함.
- 균사가 배지 전체에 고르게 퍼졌는지, 녹색·검은색 등 이상 색의 반점이 없는지 매일 관찰함. 이상 반점이 보이면 해당 배지를 격리함.

## 4. 발이 유도(원기 형성)
- 균사 배양이 끝나면 온도를 낮추고 습도를 높이며 환기와 약한 광을 주어 원기 형성을 유도함.
- 발이 유도 온도는 약 10~17 ℃ [일반 권장값, 출처 확인 필요], 상대습도는 약 90 % 이상 [일반 권장값, 출처 확인 필요]을 유지함.
- 원기는 배지 표면에 작은 좁쌀 모양의 덩어리로 나타남. 이 시기 건조하면 원기가 마르거나 기형이 생기기 쉬움.

## 5. 자실체 생육 관리
- 자실체 생육 적정 온도는 품종에 따라 다르나 대체로 약 12~18 ℃ [일반 권장값, 출처 확인 필요] 범위로 관리함. 고온성·저온성 품종이 있으므로 종균 공급처의 품종 특성표를 확인함.
- 상대습도는 약 85~95 % [일반 권장값, 출처 확인 필요]를 유지하되, 버섯 표면에 물방울이 오래 맺혀 있지 않게 함. 물방울이 맺힌 상태가 계속되면 세균성 병 발생 위험이 커짐.
- 광은 갓 색과 형태 형성에 영향을 주므로 약한 산광을 일정 시간 줌.
- 대가 길게 웃자라고 갓이 작아지면 CO2 농도가 높다는 신호일 수 있으므로 환기량을 늘림.

## 6. 환기 관리
- 버섯은 호흡하면서 CO2를 배출하므로, 생육 단계에서는 재배사 CO2 농도를 약 1,000 ppm 이하 [일반 권장값, 출처 확인 필요]로 관리하는 것이 일반적임.
- 환기 시 외부 공기가 직접 버섯에 닿으면 표면이 건조해지므로, 유입 공기의 온도·습도를 조절하거나 가습과 병행함.
- 환기는 한 번에 많이 하기보다 여러 번 나누어 하면 온도·습도 변동을 줄일 수 있음.
- CO2 센서를 설치해 측정값을 기록하면 환기 시점을 객관적으로 판단할 수 있음. 측정값은 영농일지에 함께 기록함.

## 7. 수확
- 갓 가장자리가 안쪽으로 약간 말려 있고 포자가 많이 날리기 전이 수확 적기임.
- 갓 가장자리가 펴지고 위로 젖혀지면 과숙 상태로 상품성이 떨어지고 포자 비산이 늘어남.
- 수확 후에는 배지 표면의 잔재를 정리하고, 다음 주기 발이를 위해 환경을 다시 조절함.

## 8. 병해충 관리 원칙
### 8.1 푸른곰팡이병
- 증상: 배지나 버섯 주변에 처음에는 흰색, 이후 녹색(푸른색)으로 변하는 곰팡이 균총이 나타남. 원인균은 트리코더마(Trichoderma) 속 곰팡이로 알려져 있음.
- 발생 요인: 불충분한 살균, 접종 시 오염, 고온 다습, 재배사 위생 불량.
- 방제 원칙: ① 살균 공정을 철저히 하고 기록함 ② 오염된 배지는 즉시 재배사 밖으로 반출해 격리·폐기함 ③ 재배사·도구·작업자 위생을 관리함 ④ 수확 후 폐배지를 재배사 근처에 쌓아두지 않음.
- 약제 사용은 해당 작물에 등록된 약제와 안전사용기준을 확인한 경우에만 함 [출처 확인 필요: 농약안전정보시스템에서 등록 여부 확인].

### 8.2 세균성갈색무늬병
- 증상: 갓 표면에 갈색 반점이나 무늬가 생기고, 심하면 점액질로 변하며 상품성이 크게 떨어짐. 원인균은 슈도모나스(Pseudomonas) 속 세균으로 알려져 있음.
- 발생 요인: 과습, 버섯 표면에 물방울이 오래 맺힘, 온도 변화가 커서 결로가 생기는 환경.
- 방제 원칙: ① 가습 시 버섯에 물이 직접 닿지 않게 함 ② 환기로 표면 결로를 줄임 ③ 발병한 버섯과 배지는 빨리 제거함 ④ 관수 용수의 위생을 확인함.

### 8.3 버섯파리 피해
- 증상: 성충이 재배사 안을 날아다니고, 유충이 균사나 자실체를 가해해 버섯 대와 갓에 구멍이나 갈변이 생김. 유충이 다른 병원균을 옮길 수 있음.
- 방제 원칙: ① 출입구·환기구에 방충망을 설치함 ② 끈끈이 트랩으로 발생 밀도를 모니터링함 ③ 폐배지와 잔재를 신속히 제거함 ④ 재배 주기 사이에 재배사를 청소·소독함.

## 9. 일일 점검 항목 (영농일지 기록 권장)
- 재배사 온도(℃), 상대습도(%), CO2 농도(ppm)
- 단계별 생육 상태(균사 생장 / 원기 형성 / 자실체 생장 / 수확 적기 / 과숙)
- 병해충 의심 증상과 조치 내용, 격리·폐기한 배지 수량
- 환기·가습·조명 작업 시간과 내용
- 다음 날 작업 계획
